# Telegram-бот для сообщений родителям

Бот превращает короткие заметки преподавателя английского языка в готовые сообщения родителям. Он создаёт обратную связь после урока, объявления, сообщения о каникулах, начале учебного года, расписании, переносах и оплате, а также свободные сообщения. Генерация текста выполняется через Kie.ai (модель Gemini 2.5 Flash), данные хранятся только в оперативной памяти до перезапуска приложения.

## 1. Получение Telegram Bot Token

1. Откройте в Telegram официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и укажите отображаемое имя бота.
3. Придумайте свободный username латиницей, который заканчивается на `bot`, например `EnglishParentFeedbackBot`.
4. Скопируйте выданный Telegram Bot Token.

После создания BotFather покажет ссылку вида `https://t.me/username_бота`. Именно её можно отправить преподавателю для проверки.

## 2. Получение Kie.ai API key

1. Зарегистрируйтесь на [Kie.ai](https://kie.ai/).
2. Создайте ключ на странице [API Key Management](https://kie.ai/api-key).
3. При необходимости пополните баланс аккаунта.

Ключ используется только сервером. Не публикуйте файл `.env` и не вставляйте реальные ключи в код.

## 3. Локальный запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

macOS/Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` и заполните значения:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
KIE_API_KEY=ключ_от_Kie.ai
```

Запустите бот:

```bash
python main.py
```

Затем откройте бота в Telegram, отправьте `/start`, выберите тип сообщения и пришлите заметки длиной не менее 10 символов.

## 4. Размещение на Bothost

1. Создайте Python-проект на Bothost.
2. Загрузите `main.py`, `requirements.txt`, `.env.example` и `README.md`. Для работы обязательны первые два файла; остальные служат инструкцией и образцом.
3. В настройках переменных окружения Bothost добавьте `TELEGRAM_BOT_TOKEN` и `KIE_API_KEY` с реальными значениями. Не загружайте локальный `.env` с секретами.
4. Укажите команду запуска:

```text
python main.py
```

Зависимости устанавливаются из `requirements.txt`. Бот использует long polling, поэтому отдельный webhook или база данных не нужны.

## 5. Как проверить использование AI API

Создайте любое сообщение в Telegram и убедитесь, что пришёл связный текст, а кнопки изменения создают новые варианты. Проверьте `/start` и кнопку «Главное меню» — они должны возвращать к семи типам сообщений. Затем откройте [логи Kie.ai](https://kie.ai/logs): там должен появиться запрос к Gemini 2.5 Flash и расход токенов/кредитов. Для дополнительной проверки временно уберите или исказите `KIE_API_KEY`, перезапустите бот и повторите запрос — бот должен показать сообщение о недоступности ИИ, а после возврата правильного ключа снова генерировать текст.

Интеграция использует документированный endpoint `POST https://api.kie.ai/gemini-2.5-flash/v1/chat/completions`, заголовок `Authorization: Bearer <ключ>` и стандартный формат chat completions. Актуальное описание находится в [документации Kie.ai](https://docs.kie.ai/market/gemini/gemini-2-5-flash).
